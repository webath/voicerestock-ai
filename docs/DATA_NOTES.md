## Κανόνες καθαρισμού (με αυτή τη σειρά, με counts σε κάθε βήμα)

1. Join `MTRLINES.FINDOC = SALDOC.FINDOC` (οι γραμμές **δεν** έχουν ημερομηνία ή πελάτη).
2. Πέταξε headers με `ISCANCEL=1` **και** τις γραμμές τους.
3. Πέταξε γραμμές με `MTRTYPE=1` (join με `MTRL.csv` — όχι hardcoded 5081).
4. `signed_qty = QTY1` αν `SERIES=7021`, `−QTY1` αν `SERIES=7071`.
5. Free goods (`PRICE=0, DISC1PRC=100`) **μένουν** — παραδόθηκαν πραγματικά. Μετράνε στην ποσότητα, όχι στα έσοδα.
6. Το ίδιο `MTRL` μπορεί να εμφανίζεται 2 φορές στο ίδιο παραστατικό (κανονική + δώρο) → άθροισε.
7. Aggregate σε (TRDR, MTRL, TRNDATE).

Tests (`services/forecast/tests/`): 0 ακυρωμένες ποσότητες, πιστωτικά αρνητικά, 0 μεταφορικά, `NETAMNT` = Σ`LINEVAL` ανά παραστατικό.
